## Gantt Chart & Timeline Management

A Gantt chart was used throughout the project lifecycle to visually manage tasks, milestones, deliverables, and project timelines.

The chart supported:

* Sprint planning
* Task dependency tracking
* Milestone monitoring
* Progress visualization
* Team collaboration

The Agile workflow was divided into multiple phases including planning, design, development, testing, deployment, and review


# Sprint Planning

## Sprint 1 — Requirement Analysis

 Objectives

- Understand Aspect-Based Sentiment Analysis (ABSA)
- Identify suitable restaurant review datasets
- Define project scope and deliverables

Deliverables

- Dataset selection
- Initial project proposal
- SDLC planning documentation


## Sprint 2 — Data Ingestion & Parsing

Objectives

- Load XML-based review data
- Extract aspects and sentiments
- Convert XML structure into tabular format


## Sprint 3 — NLP Preprocessing

Objectives

- Clean textual reviews
- Remove stopwords and punctuation
- Normalize text for machine learning

Deliverables

- NLP preprocessing pipeline
- Tokenization workflow


## Sprint 4 — Refactoring & Portfolio Preparation

Objectives

- Convert notebook into modular project architecture
- Improve repository structure
- Add documentation and visual outputs

Deliverables

- Modular Python scripts
- README documentation
- GitHub-ready project structure
